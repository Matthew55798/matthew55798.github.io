# AI 工程师课程：从 Java 工程师到 AI 增强系统设计者

> **一句话目标**：理解 LLM/RAG/Agent/Tool 核心概念，能在设计层面接入 AI 能力，用 AI 工具辅助设计和理解。
>
> **适合人群**：2-8 年经验 Java 工程师，熟悉 Spring Boot，对 AI 了解有限。
>
> **课程产出**：一套完整的"AI 增强后台系统"设计方案（架构演进图 + 多份设计文档）。

---

| 0.3 | Embedding 与向量世界 | 向量空间、相似度计算、高维降维直觉 | **Embedding 使用决策图**：何时需要、如何选择 |

## 课程设计原则

1. **概念优先，代码辅助**：每章 80% 概念讲解 + 20% 伪代码示意，不写完整实现
2. **设计产出导向**：每章结束时必须产出一份具体的设计制品（图/表/清单/规范），而非"学到了 XX"
3. **主线贯穿**：所有章节的产出最终汇成一套完整方案，不是孤立作业
4. **不教数学，教直觉**：用类比和比喻替代公式推导，用工程视角讲技术
5. **AI 作为协作工具，不是黑盒**：用 Vibe Coding 理解概念 + 生成草稿，但决策权在工程师
6. **场景驱动，非技术罗列**：每章从实际业务场景出发，而非逐个介绍 API
7. **决策点清晰**：每个技术点都标注"选什么、为什么选、不选什么"
8. **可独立使用**：每个模块可单独提取用于团队内部分享或面试准备
