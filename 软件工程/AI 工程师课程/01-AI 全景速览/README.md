## 章节目录

### 0.1 AI 全景地图

**主要概念**：
- AI → ML → DL → NLP → LLM 的层级关系
- 关键术语图谱：监督学习、无监督学习、强化学习、自监督学习
- 当前 AI 落地场景速览

**类比说明**：
- AI 是"学习"，ML 是"通过样例学习"，DL 是"通过多层次抽象学习"
- LLM 是"读过整个互联网的学生"

**设计产出**：术语对照表（每个术语的"人话"解释 + 在 Java 世界的类比）

---

### 0.2 Transformer 黑盒直觉

**主要概念**：
- Token 化：文本如何变成机器能理解的数字
- 自注意力机制：LLM 如何"理解"上下文关系
- 上下文窗口：6K / 32K / 128K 的含义与取舍
- 参数规模：7B / 70B / MoE 的概念与性能关系

**类比说明**：
- Token = 词语/子词的最小单元，类似 Java 中的"语法分析单元"
- 注意力 = 做阅读理解时自动找关键词关联，类似 Spring Boot 自动装配的"智能猜测"
- 上下文窗口 = 一次能"同时记住"的信息量，类似 JVM 堆内存大小

**设计产出**：LLM 能力边界清单（能做什么 vs 不能做什么 + 常见陷阱）

---

### 0.3 Embedding 与向量世界

**主要概念**：
- 什么是 Embedding：从文本/代码/图片到向量
- 向量空间中的相似度：余弦相似度 vs 欧氏距离
- Embedding 模型的选择：维度、训练数据、领域适配
- 高维降维直觉（t-SNE/PCA 一句话）

**类比说明**：
- Embedding 就像把"语义"翻译成"向量坐标"
- "苹果"和"橘子"离得近，"苹果"和"汽车"离得远
- 类似 Java hashCode()，但这里是"语义哈希"

**设计产出**：Embedding 使用决策图（何时需要、何时不需要、如何选择模型）
