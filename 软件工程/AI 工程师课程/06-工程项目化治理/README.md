## 章节目录

### 5.1 成本控制设计

**设计主题**：AI 的按用量收费模式

**主要概念**：
- **成本构成**：
  | 成本项 | 说明 | 优化方向 |
  |--------|------|---------|
  | Token 调用费 | 按输入 + 输出 Token 收费 | 减少用量、缓存、降级 |
  | 模型选择 | 小模型便宜，大模型贵 | 按场景选型 |
  | 向量数据库 | 存储 + 计算 | 索引优化、按需扩展 |
  | 其他 | Embedding 调用、重排序等 | 批量处理、复用 |
- **成本优化策略**：
  - **Token 预算控制**：
    - 系统 Prompt / 请求数 = 用户对话量 × 平均 Token 量 × Token 单价
    - 预算策略：每日/每月上限
  - **缓存策略**：
    - 相同 Prompt → 相同返回？（缓存命中）
    - 相似查询 → 返回缓存？（相似度阈值，降低缓存命中率）
    - 高频问题 → 预处理（FAQ 缓存）
  - **模型路由**：
    - 简单查询 → 小模型（便宜）
    - 复杂分析 → 大模型（精准）
    - 本地敏感 → 本地模型（隐私优先）
  - **降级策略**：
    - 预算用完？切到规则引擎（免费）

**设计产出**：成本优化策略图

### 5.2 延迟优化设计

**设计主题**：让 AI 响应更快

**主要概念**：
- **延迟来源**：
  | 阶段 | 耗时 | 优化方式 |
  |------|------|---------|
  | 网络请求 | ~20ms | 本地部署/边缘推理 |
  | LLM 推理 | 100ms-5s | 流式输出、小模型 |
  | RAG 检索 | ~50ms | 缓存、预计算 |
  | 总耗时 | 1-10s | 综合优化 |
- **优化策略**：
  - **流式输出**：首字节延迟 < 500ms，边生成边给用户看
  - **预计算**：提前生成（如预生成摘要）
  - **异步处理**：后台处理，不阻塞用户
  - **缓存**：缓存命中 → 0ms
  - **边缘推理**：部分场景本地化

**设计产出**：延迟优化决策树（按端到端延迟要求，从低到高）

### 5.3 安全与合规设计

**设计主题**：AI 系统的安全底线

**主要概念**：
- **安全维度**：
  | 维度 | 风险 | 防护措施 |
  |------|------|---------|
  | 数据安全 | 用户数据泄露 | 输入脱敏、输出过滤 |
  | 内容安全 | 生成不当内容 | 内容审核 API |
  | 权限安全 | AI 越权访问 | 最小权限 + 审计 |
  | 合规 | 数据出境、隐私法规 | 本地化部署、审计日志 |
- **合规要求**：
  - 中国：《生成式 AI 服务管理暂行办法》
  - 国际：GDPR、数据本地化
  - 行业特定：金融/医疗的额外要求
- **审计追溯**：
  - 记录：谁、何时、请求了什么、AI 返回了什么
  - 保留期：合规要求的最小保留期
  - 可查询：审计日志可搜索、可导出

**设计产出**：AI 系统安全合规清单（4 维表格 + 检查项）

### 5.4 可观测性设计

**设计主题**：AI 系统的行为可度量、可追踪、可反馈

**主要概念**：
- **可观测性四支柱**：
  | 支柱 | 内容 | 工具 |
  |------|------|------|
  | 日志 (Logs) | 请求/响应记录、错误日志 | ELK/Loki |
  | 指标 (Metrics) | QPS、延迟、Token 用量、错误率 | Prometheus/Grafana |
  | 追踪 (Tracing) | 请求链路追踪、Agent 决策链 | OpenTelemetry/Jaeger |
  | 反馈 (Feedback) | 用户评价、Bad Case 收集 | 评分系统 + 工单 |
- **质量评估**：
  - **自动评估**：
    - RAGAS：检索质量、生成质量、忠实度
    - 人工评估：专业标注团队
  - **用户反馈**：
    - 显式：评分按钮（👍/👎）、文字反馈
    - 隐式：停留时间、复访率
  - **Prompt 版本追踪**：
    - 哪个版本导致了 Bad Case？
    - Prompt 变更的回滚能力
- **错误分类**：
  | 错误类型 | 可能原因 | 调试方向 |
  |----------|---------|---------|
  | 幻觉 | 检索质量差 | 优化索引/检索 |
  | 答非所问 | Prompt 不清 | 优化 Prompt |
  | 速度慢 | LLM 响应慢 | 模型升级/缓存 |
  | 成本高 | Token 用量大 | 压缩 Prompt |
  | 安全问题 | 注入攻击 | 安全防护 |
