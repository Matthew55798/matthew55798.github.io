# 第一个 AI Agent

> 来源：[菜鸟教程](https://www.runoob.com/ai-agent/first-ai-agent.html)

AI Agent 平台种类繁多，但核心目的相同：让模型从回答问题升级为自动执行任务，有的主打零代码拖拽，有的强调工程化定制，也有专门做流程集成或多代理协作。

不同层级的使用场景拆成三个面向：搭建速度、系统衔接、可控深度。

## 核心需求

| 核心需求 | 推荐工具 | 关键优势 |
|---------|---------|---------|
| 0 代码生成应用 | [秒哒](https://www.miaoda.cn/?invitecode=user-93thly701s00) | 0 代码，通过一句话生成需求，并生成应用 |
| AI 应用开发平台 | [MonkeyCode](https://monkeycode-ai.com/?ic=019d94af-c5d0-7207-a923-89d7ccf67d91) | 直接在平台里创建任务，让 AI 编码，在云端开发环境中使用终端、文件管理和预览 |
| 零代码搭建对话机器人 | [扣子(Coze)](https://www.coze.cn/overview?utm_medium=daohang&utm_source=runoob&utm_term=hw_coze_runoob) | 全托管环境，靠提示词、插件、知识库即可形成可用机器人 |
| 自动化触发与系统对接 | [n8n](https://github.com/n8n-io/n8n) | 集成面广，可自托管，常规内部系统都能打通 |
| 开发者可控的深度定制 | [Dify](https://github.com/langgenius/dify) / [LangChain](https://github.com/langchain-ai/langchain) | 前者提供完整开源方案；后者适合构建复杂推理链路 |
| 多角色协作与任务分解 | [AutoGen](https://github.com/microsoft/autogen) / [CrewAI](https://github.com/crewAIInc/crewAI) | 前者强调动态协作；后者以清晰角色体系驱动流程 |

## 1、注册账号

**第一步：** 打开官网 [Coze 官网](https://www.coze.cn/overview?utm_medium=daohang&utm_source=runoob&utm_term=hw_coze_runoob) 并登录。

登录后，选择**智能体开发**（现在 OpenClaw 也支持，不过需高级用户）

---

## 2、开始搭建：三步走

我们要做的智能体叫 **大理旅行小助手**，它的功能：查天气、找景点、安排路线。

### 第一步：创建智能体

1.  点击创建智能体。
2.  **智能体名称**：填 `大理旅行小助手`。
3.  **智能体介绍**：填 `帮用户规划去大理的旅行行程`。
4.  点击 **"确认"**，进入编辑页面。

### 第二步：编写人设

在左侧的 **"人设与回复逻辑"** 输入框里，填入以下内容（直接复制）：

```
# 角色
你是一个经验丰富的大理本地导游，热情、幽默，对大理的吃喝玩乐了如指掌。

# 技能
1. 根据用户的时间和预算，规划合理的行程。
2. 推荐当地的小众景点和美食，避开游客陷阱。
3. 语气要轻松活泼，多用 Emoji。

# 限制
- 只回答与大理旅行相关的问题。
- 如果不知道答案，直接说不知道，不要瞎编。
```

### 第三步：添加插件

光有人设它只是个陪聊的，我们要给它加工具。

1.  在中间的 **"插件"** 区域，点击 `+` 号。
2.  搜索 `博查搜索`（可以调用 bing 搜索）或 `Google`，点击 **"添加"**。 *为什么要加这个？让它能联网查最新的天气和门票价格。*
3.  搜索 `墨迹天气`（或者任意天气插件），点击 **"添加"**。

---

## 3、见证奇迹的时刻

现在，看右侧的 **预览与调试** 区域。
试着对它说：

> **"我打算下周五去大理玩3天，预算2000元，喜欢安静的地方，帮我安排一下行程。"**

### 观察它在做什么：

你会看到它不会马上回答，而是显示 **"正在使用 博查搜索社区…"** 或者 **"正在使用 天气…"**。这就是 Agent 在**思考和行动**！

1.  它先去查了下周五大理的天气。
2.  它去搜了适合"安静"的景点（比如喜洲古镇、沙溪）。
3.  最后它综合信息，给你写出了一份带天气提醒的行程单。
