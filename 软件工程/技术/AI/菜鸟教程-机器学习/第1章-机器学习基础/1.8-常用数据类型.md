# 常用数据类型

本章将为你介绍机器学习中最常见的四种数据类型：数值型、文本型、图像型和类别型数据。

**数据类型就像是食材的种类**，不同的食材需要不同的处理方法。同样，不同类型的数据也需要不同的处理技术和算法。

## 数值型数据

### 什么是数值型数据？

**数值型数据就像尺子测量的结果**，可以进行数学运算，是机器学习中最常见的数据类型。

### 数值型数据的分类

#### 1\. 连续型数值数据

- 特点：可以取任意值，如身高、体重、温度
- 例子：房价、股票价格、温度

#### 2. 离散型数值数据

- 特点：只能取特定值，如人数、计数
- 例子：顾客数量、产品评分

### 数值型数据的处理方法

```python
# 数值型数据处理方法  
from sklearn.preprocessing import MinMaxScaler, StandardScaler, RobustScaler  

def normalize_data(data, method='minmax'):  
    """数据标准化"""  
    if method == 'minmax':  
        scaler = MinMaxScaler()  
    elif method == 'standard':  
        scaler = StandardScaler()  
    elif method == 'robust':  
        scaler = RobustScaler()  
      
    return scaler.fit_transform(data)  

def detect_outliers(data, method='iqr'):  
    """检测异常值"""  
    outliers_info = {}  
      
    for column in data.select_dtypes(include=[np.number]).columns:  
        if method == 'iqr':  
            Q1 = data[column].quantile(0.25)  
            Q3 = data[column].quantile(0.75)  
            IQR = Q3 - Q1  
            lower_bound = Q1 - 1.5 * IQR  
            upper_bound = Q3 + 1.5 * IQR  
            outliers = data[(data[column] < lower_bound) | (data[column] > upper_bound)]  
      
    return outliers  
```

## 文本型数据

### 什么是文本型数据？

**文本型数据就像人类语言的表达**，包含丰富的语义信息，但需要特殊处理才能被机器学习模型使用。

### 文本型数据的分类

#### 1\. 结构化文本数据

- 特点：有固定格式，如邮箱、日期
- 例子：评论文本、搜索查询

#### 2\. 非结构化文本数据

- 特点：无固定格式，需要分词处理
- 例子：文章、聊天记录

### 文本数据处理方法

```python
# 文本数据处理方法  
import re  

def clean_text(text):  
    """文本清洗"""  
    # 移除特殊字符和数字  
    text = re.sub(r'[^\u4e00-\u9fff\s]', '', text)  
    # 移除多余空格  
    text = re.sub(r'\s+', ' ', text).strip()  
    return text  

def tokenize_chinese(text):  
    """中文分词（简化版）"""  
    # 实际项目中建议使用 jieba 库  
    words = text.split()  
    stop_words = {'的', '了', '在', '是', '我', '有'}  
    words = [word for word in words if word not in stop_words and len(word) > 1]  
    return words  

from sklearn.feature_extraction.text import TfidfVectorizer  

def extract_features(texts, method='tfidf'):  
    """特征提取"""  
    if method == 'tfidf':  
        vectorizer = TfidfVectorizer(max_features=1000)  
    else:  
        vectorizer = CountVectorizer(max_features=1000)  
      
    features = vectorizer.fit_transform(texts)  
    return features.toarray(), vectorizer.get_feature_names_out()  
```

## 图像型数据

### 什么是图像型数据？

**图像型数据就像视觉世界的数字化表达**，由像素点组成，包含丰富的空间和颜色信息。

### 图像型数据的分类

#### 1\. 灰度图像

- 特点：单通道，像素值 0-255
- 表示：2D 数组

#### 2\. 彩色图像

- 特点：RGB三通道
- 表示：3D 数组 (height, width, 3)

### 图像数据处理方法

```python
# 图像数据处理方法  
from skimage import filters, feature, transform  
from skimage.color import rgb2gray  

def resize_image(image, target_size):  
    """调整图像大小"""  
    return transform.resize(image, target_size, anti_aliasing=True)  

def normalize_image(image):  
    """图像归一化"""  
    return (image - image.min()) / (image.max() - image.min())  

def extract_color_features(image):  
    """提取颜色特征"""  
    if len(image.shape) == 3:  # 彩色图像  
        features = {}  
        for i, channel in enumerate(['R', 'G', 'B']):  
            channel_data = image[:, :, i]  
            features[f'{channel}_mean'] = np.mean(channel_data)  
            features[f'{channel}_std'] = np.std(channel_data)  
        return features  

def augment_image(image):  
    """图像增强"""  
    augmented = []  
    augmented.append(image)  
    augmented.append(np.fliplr(image))  # 水平翻转  
    augmented.append(np.flipud(image))   # 垂直翻转  
    augmented.append(np.rot90(image))   # 旋转90度  
    return augmented  
```

## 类别型数据

### 什么是类别型数据？

**类别型数据就像分类标签**，表示不同的类别或分组，不能进行数学运算。

### 类别型数据的分类

#### 1\. 名义型数据

- 特点：类别之间无顺序关系
- 例子：性别、血型、城市

#### 2\. 有序型数据

- 特点：类别之间有顺序关系
- 例子：质量等级、满意度

### 类别型数据处理方法

```python
# 类别型数据处理方法  
from sklearn.preprocessing import LabelEncoder, OneHotEncoder, OrdinalEncoder  

def label_encoding(data, columns):  
    """标签编码"""  
    for column in columns:  
        encoder = LabelEncoder()  
        data[f'{column}_encoded'] = encoder.fit_transform(data[column])  
    return data  

def one_hot_encoding(data, columns):  
    """独热编码"""  
    for column in columns:  
        encoder = OneHotEncoder(sparse=False, drop='first')  
        encoded_features = encoder.fit_transform(data[[column]])  
        feature_names = [f'{column}_{cat}' for cat in encoder.categories_[0][1:]]  
        for i, name in enumerate(feature_names):  
            data[name] = encoded_features[:, i]  
    return data  

def ordinal_encoding(data, column, categories):  
    """有序编码"""  
    encoder = OrdinalEncoder(categories=[categories])  
    data[f'{column}_ordinal'] = encoder.fit_transform(data[[column]])  
    return data  

def target_encoding(data, categorical_column, target_column):  
    """目标编码"""  
    target_means = data.groupby(categorical_column)[target_column].mean()  
    data[f'{categorical_column}_target'] = data[categorical_column].map(target_means)  
    return data  

def frequency_encoding(data, columns):  
    """频率编码"""  
    for column in columns:  
        frequency = data[column].value_counts(normalize=True)  
        data[f'{column}_frequency'] = data[column].map(frequency)  
    return data  
```

## 多模态数据融合

在实际应用中，经常需要处理多种类型的数据，这就是**多模态数据**。

### 数据类型融合示例

```python
# 多模态数据融合示例  
class MultiModalDataProcessor:  
    def __init__(self):  
        pass  
      
    def create_multimodal_dataset(self):  
        """创建多模态数据集"""  
        n_samples = 100  
          
        # 数值特征  
        numeric_features = {  
            '年龄': np.random.randint(18, 65, n_samples),  
            '收入': np.random.normal(50000, 15000, n_samples),  
            '工作经验': np.random.randint(0, 20, n_samples)  
        }  
          
        # 类别特征  
        categorical_features = {  
            '城市': np.random.choice(['北京', '上海', '广州'], n_samples),  
            '学历': np.random.choice(['本科', '硕士', '博士'], n_samples)  
        }  
          
        # 文本特征（简化）  
        text_features = {  
            '评论': ['好评' if np.random.rand() > 0.3 else '一般' for _ in range(n_samples)]  
        }  
          
        return {**numeric_features, **categorical_features, **text_features}  
```
