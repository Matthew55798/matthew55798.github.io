# 3.13 分类指标

> 来源：https://www.runoob.com/ml/ml-classification-metrics.html

---

在机器学习的世界里，构建一个分类模型只是第一步。我们需要一套科学的**体检指标**来评估模型的健康状况。这些指标就是**分类指标**。

---

## 为什么需要分类指标？

不同的业务场景关注的重点不同：

-   **疾病诊断**：我们更关心别漏掉任何一个病人（高召回率），哪怕多检查一些健康的人。
-   **垃圾邮件过滤**：我们更关心别把重要邮件扔进垃圾箱（高精确率），哪怕漏掉一些垃圾邮件。

---

## 核心概念：混淆矩阵

混淆矩阵是一个表格，展示了模型预测结果与真实标签之间的所有四种可能情况。

| 术语 | 缩写 | 含义 |
|---|---|---|
| **真正例** | TP | 模型预测为正，真实也是正 |
| **假正例** | FP | 模型预测为正，但真实是负（Type I Error） |
| **真负例** | TN | 模型预测为负，真实也是负 |
| **假负例** | FN | 模型预测为负，但真实是正（Type II Error） |

**记忆技巧**：

-   **真/假** 指的是**预测是否正确**。
-   **正/负** 指的是**模型的预测结果**。

---

## 核心分类指标详解

### 1. 准确率 - 最直观的指标

准确率衡量了模型预测正确的样本占总样本的比例。

准确率 = (TP + TN) / (TP + TN + FP + FN)

```python
from sklearn.metrics import accuracy_score
accuracy = accuracy_score(y_true, y_pred)
print(f"准确率: {accuracy:.2f}")
```

**局限**：在**数据不平衡**时具有误导性。

### 2. 精确率 - "宁缺毋滥"的指标

精确率关注模型预测出的**正例**中有多少是真正的正例。

精确率 = TP / (TP + FP)

```python
from sklearn.metrics import precision_score
precision = precision_score(y_true, y_pred)
print(f"精确率: {precision:.2f}")
```

### 3. 召回率 - "宁可错杀"的指标

召回率关注所有真实的**正例**中被模型找出了多少。

召回率 = TP / (TP + FN)

```python
from sklearn.metrics import recall_score
recall = recall_score(y_true, y_pred)
print(f"召回率: {recall:.2f}")
```

### 4. F1 分数 - 精确率与召回率的调和平均

F1 分数是精确率和召回率的调和平均数，旨在找到一个平衡点。

F1 = 2 × (精确率 × 召回率) / (精确率 + 召回率)

```python
from sklearn.metrics import f1_score
f1 = f1_score(y_true, y_pred)
print(f"F1分数: {f1:.2f}")
```

### 指标对比与选择指南

| 指标 | 关注点 | 适用场景举例 |
|---|---|---|
| **准确率** | 整体预测正确率 | 类别均衡，且 FP 和 FN 代价相似的场景。 |
| **精确率** | 预测为正的样本的准确性 | FP 代价高：如垃圾邮件过滤、推荐系统。 |
| **召回率** | 真实为正的样本被找出的比例 | FN 代价高：如疾病筛查、欺诈检测。 |
| **F1 分数** | 精确率与召回率的平衡 | 需要综合考量，没有明确偏向的场景。 |

## 进阶指标：ROC 曲线与 AUC

### 1. ROC 曲线

ROC 曲线以 **FPR 为横轴**，**TPR 为纵轴**。曲线上的每一个点，都对应一个特定的分类阈值。

-   **理想点**：左上角 (0, 1)，即 FPR=0，TPR=1。
-   **随机线**：从 (0,0) 到 (1,1) 的对角线。

### 2. AUC 值

AUC 是 ROC 曲线下的面积。

-   **AUC = 1**：完美模型。
-   **AUC = 0.5**：模型没有区分能力。
-   **0.5 < AUC < 1**：模型具有一定的预测能力，值越大越好。

```python
from sklearn.metrics import roc_curve, auc
fpr, tpr, thresholds = roc_curve(y_true, y_scores)
roc_auc = auc(fpr, tpr)
print(f"AUC 值: {roc_auc:.2f}")
```

---

## 多分类问题的指标

当类别超过两个时，可以使用：

1.  **宏平均**：先计算每个类别的指标，再对所有类别的指标取算术平均。
2.  **微平均**：先汇总所有类别的 TP、FP 等，再用汇总后的值计算一个全局指标。

```python
from sklearn.metrics import precision_score
precision_macro = precision_score(y_true, y_pred, average='macro')
precision_micro = precision_score(y_true, y_pred, average='micro')
```

## 实践练习：综合评估一个分类模型

```python
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import classification_report, confusion_matrix, accuracy_score

# 1. 加载数据
iris = load_iris()
X = iris.data
y = iris.target
target_names = iris.target_names

# 2. 划分训练集和测试集
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

# 3. 训练一个简单的逻辑回归模型
model = LogisticRegression(max_iter=200)
model.fit(X_train, y_train)

# 4. 在测试集上进行预测
y_pred = model.predict(X_test)

# 5. 计算并打印各种指标
print("=== 混淆矩阵 ===")
print(confusion_matrix(y_test, y_pred))

print("\n=== 分类报告 ===")
print(classification_report(y_test, y_pred, target_names=target_names))

print(f"\n=== 准确率 ===")
print(f"{accuracy_score(y_test, y_pred):.4f}")
```
