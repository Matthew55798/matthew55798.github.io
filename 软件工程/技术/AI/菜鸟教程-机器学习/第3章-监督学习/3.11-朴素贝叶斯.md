# 3.11 朴素贝叶斯

> 来源：https://www.runoob.com/ml/ml-naive-bayes.html

---

朴素贝叶斯是一种基于 **贝叶斯定理** 的简单而高效的 **概率分类算法**。

朴素贝叶斯的核心思想是：通过已知的某些特征，来计算某个事件发生的概率，并选择概率最高的类别作为预测结果。

它的朴素（Naive）之处在于一个关键假设：**所有特征之间是相互独立的**。

---

## 核心原理：贝叶斯定理

贝叶斯定理描述了在已知一些条件的情况下，如何更新某个事件发生的概率。

### 贝叶斯公式

P(A|B) = [P(B|A) * P(A)] / P(B)

**场景**：判断一封邮件是否是垃圾邮件（Spam）。

-   **P(A)**： 任意一封邮件是垃圾邮件的先验概率。
-   **P(B|A)**： 在已知邮件是垃圾邮件的情况下，其中出现某个词的条件概率。
-   **P(A|B)**： 在已知邮件包含某个词的条件下，这封邮件是垃圾邮件的后验概率。

### "朴素"在哪里？

真正的贝叶斯分类器在计算 `P(B|A)` 时，需要考虑所有特征的联合概率，这非常复杂。

朴素贝叶斯做出了一个简化的假设：**所有特征都相互条件独立**：

P(B1, B2, B3... | A) ≈ P(B1|A) * P(B2|A) * P(B3|A) * ...

---

## 分类器类型

| 分类器类型 | 适用特征数据类型 | 说明 |
|---|---|---|
| **高斯朴素贝叶斯** | 连续型数据 | 假设每个特征在每个类别下服从高斯分布。 |
| **多项式朴素贝叶斯** | 离散型计数数据 | 特别适用于文本分类，特征通常是单词的出现次数或 TF-IDF 值。 |
| **伯努利朴素贝叶斯** | 二值型数据 | 假设特征是二值的（出现或不出现），关注是否出现。 |

## 动手实践：用 Python 实现垃圾邮件分类

### 1. 场景与数据准备

```python
# 示例训练数据
train_data = [
    ("免费获取 iPhone 大奖！点击链接", "spam"),
    ("老板，下午三点开会，请准时参加", "ham"),
    ("恭喜您中奖了！立即领取您的奖金", "spam"),
    ("项目报告已发到您的邮箱，请查收", "ham"),
    ("限时特价，全场五折，仅限今天", "spam"),
    ("周末聚餐定在晚上七点，老地方", "ham")
]
```

### 2. 代码实现步骤

```python
# 导入必要的库
from sklearn.feature_extraction.text import CountVectorizer
from sklearn.naive_bayes import MultinomialNB
from sklearn.pipeline import make_pipeline
import numpy as np

# 准备数据
texts = [data[0] for data in train_data]
labels = [data[1] for data in train_data]

# 创建并训练模型管道
model = make_pipeline(CountVectorizer(), MultinomialNB())
model.fit(texts, labels)

# 准备新邮件进行预测
new_emails = [
    "免费领取优惠券，机会难得！",  # 预期为 spam
    "明天上午十点电话会议讨论预算"   # 预期为 ham
]

# 进行预测
predictions = model.predict(new_emails)
prediction_proba = model.predict_proba(new_emails)

# 获取模型的类别顺序
class_names = model.classes_
for email, pred, proba in zip(new_emails, predictions, prediction_proba):
    print(f'邮件内容: "{email}"')
    print(f"  预测类别: {pred}")
    for cls, prob in zip(class_names, proba):
        print(f"  属于'{cls}'的概率: {prob:.4f}")
    print("-" * 40)
```

## 优缺点与注意事项

### 优点

-   **简单高效**：原理简单，训练和预测速度非常快。
-   **对小规模数据表现好**：即使训练数据不多，也能取得不错的效果。
-   **适合高维数据**：特别擅长处理像文本这样特征维度非常高的数据。

### 缺点与注意事项

-   **"朴素"假设的局限性**：现实中特征往往相关，这个强假设可能影响精度。
-   **零概率问题**：如果某个特征在训练集的某个类别中从未出现，那么它的条件概率为 0，会导致整个后验概率为 0。常用 **拉普拉斯平滑**来解决（在 sklearn 中通过 alpha 参数设置）。
