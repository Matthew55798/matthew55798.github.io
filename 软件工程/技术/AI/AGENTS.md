# AI 目录指南

**Updated:** 2026-07-05

## OVERVIEW

AI、机器学习、智能体、LLM 应用工程与 AI Coding 的集中知识区。

## SCOPE

- 当前目录：`软件工程/技术/AI/`
- 本文件约束 AI 专题目录及其所有子目录。

## STRUCTURE

### 子目录

- `AI工程/`：基础模型应用工程专题，覆盖评估、提示工程、RAG、微调、数据集与推理优化。
- `LLM业务实战/`：大语言模型业务应用教程，按章节组织 LLM 基础、分类、聚类、提示、多模态与微调。
- `Vibe Coding/`：AI Coding / Vibe Coding 团队实践、工具链与工作流资料。
- `菜鸟教程-AI Agent/`：AI Agent 教程集合，覆盖基础概念、工具平台、AI Coding 工具和 Python 智能体实现。
- `菜鸟教程-机器学习/`：机器学习教程集合，覆盖基础、数据处理、监督/无监督学习、强化学习、深度学习与实战案例。

## CONVENTIONS

- 新增 Markdown 文档优先放在最贴近主题的子目录，不要散落到 `软件工程/技术/` 根目录。
- Docsify 链接使用从站点根开始的绝对路径；新增 Markdown 文件名尽量使用下划线 `_`，避免在链接中维护 `%20`。
- 历史文件如果仍包含空格，链接中需要使用 `%20`；迁移文件名时必须同步更新 `_sidebar.md` 和所有 Markdown 互链。
- 图片统一放在 `/img/技术/` 下按主题分目录管理，Markdown 中不要使用相对图片路径。
- 章节型文件保持现有编号和中文标题格式，不为补齐编号而改名。
- `LLM业务实战/` 与 `Vibe Coding/` 已归入本 AI 专题目录；侧边栏应保持同样层级。

## NOTES

- 移动、增加或删除本目录关键内容后，同步更新本地 `AGENTS.md` 和根导航中相关路径。
- 参考资料或整本资料归档仍放入 `软件工程/技术/参考资料/`，正文只保留必要摘要和链接。
