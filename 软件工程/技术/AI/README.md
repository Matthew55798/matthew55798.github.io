# Java 工程师 AI 课程体系

> 面向 2-8 年经验 Java 工程师的 AI 系统架构设计课程

## 课程定位

本课程**聚焦架构设计**，帮助 Java 工程师理解如何将 AI 能力接入现有系统。课程**不深入代码实现**，重点培养设计决策能力。

### 目标人群
- 2-8 年 Java 开发经验
- 熟悉 Spring Boot 生态
- 对 AI 了解有限，希望系统性学习

### 课程目标
1. 理解 LLM/RAG/Agent/Tool 核心概念与能力边界
2. 能在设计层面将 AI 能力接入现有系统
3. 能用 AI 工具辅助理解、设计、验证方案（Vibe Coding）
4. 最终能独立完成"AI 增强系统"的架构设计

### 课程主线

以**电商客服系统 AI 增强之旅**为主线案例，展示从传统系统到 AI 增强系统的渐进式设计演进：

```
基线系统 → LLM 问答接入 → RAG 增强 → Agent 化升级 → Tool 集成 → 完整 AI 增强系统
```

## 核心设计原则

1. **理论服务于设计**：原理讲解为设计决策提供依据，不追求理论深度
2. **能力导向产出**：每章都有明确的设计产出物（图、文档、决策表）
3. **渐进式演进**：跟随主线案例逐步构建完整系统设计
4. **AI 辅助而非替代**：教授如何与 AI 协作完成设计，而非依赖 AI 替你做决定
5. **工程化思维**：关注成本、延迟、安全、可维护性等工程问题

## 关于代码实现

**本课程不聚焦于代码实现**，而是培养设计能力。如果你需要代码参考：

- 课程中可能包含配置示意或伪代码
- 实际实现可参考官方文档和开源项目
- 设计文档完成后，实现是相对标准化的工作

**记住**：好的架构设计能让实现变得简单，而糟糕的架构会让最好的代码也难以维护。
