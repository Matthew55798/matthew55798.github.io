# 0.1 AI 全景与演进脉络

## 本章目标

建立 AI 技术的整体认知，能够基于场景做出技术选型决策。

## 核心知识点

### 1. AI / ML / DL / LLM 的关系图谱

```
人工智能 (AI)
    ├── 符号 AI（规则、专家系统）
    ├── 机器学习 (ML)
    │       ├── 监督学习
    │       ├── 无监督学习
    │       └── 强化学习
    │           └── 深度学习 (DL)
    │                   └── 大语言模型 (LLM)
    └── 计算机视觉、语音识别等
```

**关键认知：**
- LLM 是深度学习的一个分支应用
- 不是所有 AI 问题都需要 LLM
- 规则系统在某些场景仍然是最优解

### 2. 从符号 AI 到连接主义的演进

**符号 AI（1950s-1980s）**
- 基于人工编写的规则
- 可解释性强，但难以处理复杂场景
- 典型代表：专家系统

**机器学习（1980s-2010s）**
- 从数据中学习模式，而非人工编写规则
- 需要特征工程
- 典型代表：决策树、SVM、随机森林

**深度学习（2010s-现在）**
- 自动学习特征表示
- 需要大量数据和算力
- 典型代表：CNN、RNN、Transformer

**大语言模型（2020s-现在）**
- 基于 Transformer 架构
- 海量文本预训练
- 涌现能力：上下文学习、推理、代码生成

### 3. 生成式 AI 与判别式 AI

| 维度 | 判别式 AI | 生成式 AI |
|------|-----------|-----------|
| 任务 | 分类、回归、判断 | 生成新内容 |
| 典型模型 | 传统 ML 模型 | GPT、Stable Diffusion |
| 输出 | 标签、数值 | 文本、图像、代码 |
| 应用 | 垃圾邮件检测、风控 | 问答、创作、代码补全 |

### 4. LLM 的定位

**通用 vs 专业：**
- 通用 LLM（GPT-4、Claude）：知识广泛，适合通用场景
- 专业模型（CodeLlama、医疗大模型）：特定领域能力更强

**封闭 vs 开放：**
- 封闭模型（GPT-4、Claude）：通过 API 调用，能力强但不可控
- 开放模型（Llama、Qwen）：可本地部署，可控但需要更多资源

### 场景-技术匹配决策清单

| 场景特征 | 推荐技术 | 不推荐 | 原因 |
|----------|----------|--------|------|
| 确定性规则可描述 | 规则引擎 | LLM | 成本低、可解释、确定性强 |
| 结构化数据预测 | 传统 ML | LLM | 效率高、成本低 |
| 开放式问答 | LLM + RAG | 纯规则 | 灵活性高、知识面广 |
| 代码生成 | LLM | 模板 | 适应性强、上下文理解 |
| 多轮对话 | LLM + Memory | 单次调用 | 上下文连贯 |
| 需要外部数据 | RAG/Agent | 纯 LLM | 知识时效性 |
