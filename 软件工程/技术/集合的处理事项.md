# 集合的处理事项

> 参考：JavaGuide《[Java 集合使用注意事项总结](https://javaguide.cn/java/collection/java-collection-precautions-for-use.html)》，原文基于《阿里巴巴 Java 开发手册》整理。本文按本知识库格式收录，保留主要代码示例和结论。

## 集合判空

《阿里巴巴 Java 开发手册》的描述如下：

> 判断所有集合内部的元素是否为空，使用 `isEmpty()` 方法，而不是 `size() == 0` 的方式。

这是因为 `isEmpty()` 方法的可读性更好，并且时间复杂度通常为 `O(1)`。

绝大部分集合的 `size()` 方法时间复杂度也是 `O(1)`，但也有例外，例如 `java.util.concurrent` 包下的 `ConcurrentLinkedQueue`。`ConcurrentLinkedQueue` 的 `isEmpty()` 通过 `first()` 判断，`first()` 返回队列中第一个值不为 `null` 的节点。

```java
public boolean isEmpty() {
    return first() == null;
}

Node<E> first() {
    restartFromHead:
    for (;;) {
        for (Node<E> h = head, p = h, q;;) {
            boolean hasItem = (p.item != null);
            if (hasItem || (q = p.next) == null) {
                updateHead(h, p);
                return hasItem ? p : null;
            } else if (p == q) {
                continue restartFromHead;
            } else {
                p = q;
            }
        }
    }
}
```

而 `size()` 需要遍历链表，时间复杂度为 `O(n)`：

```java
public int size() {
    int count = 0;
    for (Node<E> p = first(); p != null; p = succ(p)) {
        if (p.item != null) {
            if (++count == Integer.MAX_VALUE) {
                break;
            }
        }
    }
    return count;
}
```

此外，`ConcurrentHashMap` 在不同 JDK 版本中 `size()` 和 `isEmpty()` 的实现也不完全一样。JDK 1.7 将元素数量存储在每个 `Segment` 中，`size()` 需要统计每个 `Segment` 的数量，而 `isEmpty()` 只需要找到第一个不为空的 `Segment`。JDK 1.8 中二者都会调用 `sumCount()`，复杂度与计数单元有关。

```java
final long sumCount() {
    CounterCell[] as = counterCells; CounterCell a;
    long sum = baseCount;
    if (as != null) {
        for (int i = 0; i < as.length; ++i) {
            if ((a = as[i]) != null) {
                sum += a.value;
            }
        }
    }
    return sum;
}
```

## 集合转 Map

《阿里巴巴 Java 开发手册》的描述如下：

> 在使用 `java.util.stream.Collectors` 类的 `toMap()` 方法转为 `Map` 集合时，一定要注意当 value 为 `null` 时会抛 NPE 异常。

示例：

```java
class Person {
    private String name;
    private String phoneNumber;
    // getters and setters
}

List<Person> bookList = new ArrayList<>();
bookList.add(new Person("jack", "18163138123"));
bookList.add(new Person("martin", null));

// 空指针异常
bookList.stream().collect(Collectors.toMap(Person::getName, Person::getPhoneNumber));
```

原因是 `Collectors.toMap()` 内部会调用 `Map.merge()`：

```java
public static <T, K, U, M extends Map<K, U>>
Collector<T, ?, M> toMap(Function<? super T, ? extends K> keyMapper,
                         Function<? super T, ? extends U> valueMapper,
                         BinaryOperator<U> mergeFunction,
                         Supplier<M> mapSupplier) {
    BiConsumer<M, T> accumulator =
            (map, element) -> map.merge(keyMapper.apply(element),
                    valueMapper.apply(element), mergeFunction);
    return new CollectorImpl<>(mapSupplier, accumulator, mapMerger(mergeFunction), CH_ID);
}
```

`Map.merge()` 会先检查 value 是否为 `null`：

```java
default V merge(K key, V value,
        BiFunction<? super V, ? super V, ? extends V> remappingFunction) {
    Objects.requireNonNull(remappingFunction);
    Objects.requireNonNull(value);
    V oldValue = get(key);
    V newValue = (oldValue == null) ? value :
            remappingFunction.apply(oldValue, value);
    if (newValue == null) {
        remove(key);
    } else {
        put(key, newValue);
    }
    return newValue;
}
```

另外，`Collectors.toMap()` 如果不传 `mergeFunction`，遇到 key 冲突会抛异常。因此实际开发中建议显式指定冲突处理逻辑，并提前处理 `null` value。

## 集合遍历

《阿里巴巴 Java 开发手册》的描述如下：

> 不要在 foreach 循环里进行元素的 `remove/add` 操作。remove 元素请使用 `Iterator` 方式，如果并发操作，需要对 `Iterator` 对象加锁。

foreach 语法底层依赖 `Iterator`。如果在 foreach 中直接调用集合自身的 `remove()` 或 `add()`，而不是 `Iterator.remove()`，迭代器会检测到集合被意外修改，从而抛出 `ConcurrentModificationException`。这就是单线程下也可能出现的 fail-fast 机制。

> fail-fast 机制：多个线程对 fail-fast 集合进行修改时，可能会抛出 `ConcurrentModificationException`；即使是单线程，如果遍历期间使用了错误的修改方式，也可能触发。

Java 8 开始，可以使用 `Collection#removeIf()` 删除满足条件的元素：

```java
List<Integer> list = new ArrayList<>();
for (int i = 1; i <= 10; ++i) {
    list.add(i);
}
list.removeIf(item -> item % 2 == 0);
System.out.println(list); // [1, 3, 5, 7, 9]
```

可选方式：

- 使用 `Iterator` 的 `remove()`。
- 使用普通 `for` 循环，并注意下标变化。
- 使用 fail-safe 集合类，例如 `java.util.concurrent` 包下的集合。

## 集合去重

《阿里巴巴 Java 开发手册》的描述如下：

> 可以利用 `Set` 元素唯一的特性，快速对集合进行去重，避免使用 `List.contains()` 进行遍历去重或判断包含操作。

示例：

```java
public static <T> Set<T> removeDuplicateBySet(List<T> data) {
    if (CollectionUtils.isEmpty(data)) {
        return new HashSet<>();
    }
    return new HashSet<>(data);
}

public static <T> List<T> removeDuplicateByList(List<T> data) {
    if (CollectionUtils.isEmpty(data)) {
        return new ArrayList<>();
    }
    List<T> result = new ArrayList<>(data.size());
    for (T current : data) {
        if (!result.contains(current)) {
            result.add(current);
        }
    }
    return result;
}
```

核心差异在 `contains()`：

- `HashSet.contains()` 底层依赖 `HashMap.containsKey()`，无严重哈希冲突时接近 `O(1)`。
- `ArrayList.contains()` 需要遍历数组，时间复杂度是 `O(n)`。

`HashSet` 的实现：

```java
private transient HashMap<E, Object> map;

public boolean contains(Object o) {
    return map.containsKey(o);
}
```

`ArrayList` 的实现：

```java
public boolean contains(Object o) {
    return indexOf(o) >= 0;
}

public int indexOf(Object o) {
    if (o == null) {
        for (int i = 0; i < size; i++) {
            if (elementData[i] == null) {
                return i;
            }
        }
    } else {
        for (int i = 0; i < size; i++) {
            if (o.equals(elementData[i])) {
                return i;
            }
        }
    }
    return -1;
}
```

## 集合转数组

《阿里巴巴 Java 开发手册》的描述如下：

> 使用集合转数组的方法，必须使用集合的 `toArray(T[] array)`，传入的是类型完全一致、长度为 0 的空数组。

如果不传参数，`toArray()` 返回的是 `Object[]`，容易导致类型转换问题。推荐写法：

```java
String[] array = new String[]{
    "dog", "lazy", "a", "over", "jumps", "fox", "brown", "quick", "A"
};
List<String> list = Arrays.asList(array);
Collections.reverse(list);

array = list.toArray(new String[0]);
```

`new String[0]` 起模板作用，用来指定返回数组类型。长度为 0 可以让 JVM 根据集合大小创建合适的新数组，现代 JVM 对这种写法有优化。

## 数组转集合

《阿里巴巴 Java 开发手册》的描述如下：

> 使用工具类 `Arrays.asList()` 把数组转换成集合时，不能使用其修改集合相关的方法，它的 `add/remove/clear` 方法会抛出 `UnsupportedOperationException` 异常。

常见写法：

```java
String[] myArray = {"Apple", "Banana", "Orange"};
List<String> myList = Arrays.asList(myArray);

List<String> myList2 = Arrays.asList("Apple", "Banana", "Orange");
```

JDK 源码中的说明是：返回由指定数组支持的固定大小列表。这个列表是数组和集合 API 之间的桥梁。

```java
public static <T> List<T> asList(T... a) {
    return new ArrayList<>(a);
}
```

### 基本类型数组问题

`Arrays.asList()` 是泛型方法，传递的数组必须是对象数组，而不是基本类型数组。

```java
int[] myArray = {1, 2, 3};
List<int[]> myList = Arrays.asList(myArray);

System.out.println(myList.size()); // 1
System.out.println(myList.get(0)); // 数组对象
```

当传入基本类型数组时，`Arrays.asList()` 得到的参数不是数组中的每个元素，而是数组对象本身。因此列表中只有一个元素，即这个数组对象。

正确写法：

```java
Integer[] myArray = {1, 2, 3};
List<Integer> myList = Arrays.asList(myArray);
```

### 不支持结构性修改

`Arrays.asList()` 返回的不是 `java.util.ArrayList`，而是 `java.util.Arrays` 的内部类。它支持 `get()`、`set()` 等操作，但不支持 `add()`、`remove()`、`clear()` 这类结构性修改。

```java
List<Integer> myList = Arrays.asList(1, 2, 3);

myList.add(4);    // UnsupportedOperationException
myList.remove(1); // UnsupportedOperationException
myList.clear();   // UnsupportedOperationException
```

原因是 `AbstractList` 中这些方法默认抛出 `UnsupportedOperationException`：

```java
public E remove(int index) {
    throw new UnsupportedOperationException();
}

public boolean add(E e) {
    add(size(), e);
    return true;
}

public void add(int index, E element) {
    throw new UnsupportedOperationException();
}
```

### 正确转换为 ArrayList

手动转换：

```java
static <T> List<T> arrayToList(final T[] array) {
    final List<T> result = new ArrayList<>(array.length);
    for (final T item : array) {
        result.add(item);
    }
    return result;
}
```

使用构造方法：

```java
List<String> list = new ArrayList<>(Arrays.asList("a", "b", "c"));
```

使用 Java 8 Stream：

```java
Integer[] array = {1, 2, 3};
List<Integer> list = Arrays.stream(array).collect(Collectors.toList());

int[] intArray = {1, 2, 3};
List<Integer> intList = Arrays.stream(intArray).boxed().collect(Collectors.toList());
```

使用 Guava：

```java
List<String> immutableList = ImmutableList.of("string", "elements");
List<String> immutableCopy = ImmutableList.copyOf(aStringArray);

List<String> list1 = Lists.newArrayList(anotherListOrCollection);
List<String> list2 = Lists.newArrayList(aStringArray);
List<String> list3 = Lists.newArrayList("or", "string", "elements");
```

使用 Apache Commons Collections：

```java
List<String> list = new ArrayList<>();
CollectionUtils.addAll(list, str);
```

使用 Java 9 `List.of()`：

```java
Integer[] array = {1, 2, 3};
List<Integer> list = List.of(array);
```

需要注意：`List.of()` 返回的是不可变集合，不能执行 `add()`、`remove()` 等结构性修改。
