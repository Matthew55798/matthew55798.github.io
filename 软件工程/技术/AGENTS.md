## CONVENTIONS

### 文件组织
- 新增 Markdown 文档优先放入最贴近主题的子目录，不要散落在 `软件工程/技术/` 根目录。
- `AI/` 统一承载 AI工程、LLM业务实战、Vibe Coding、AI Agent、机器学习等 AI 专题。
- `参考资料/` 是本地资料归档目录，不展示在 sidebar；正文只保留必要摘要和链接。
- README 文件可作为分区说明，不纳入 `_sidebar.md`。

### Markdown 文件命名
- 新增 Markdown 文档文件名尽量不要使用空格，使用下划线 `_` 分隔语义段，例如 `第1章_大语言模型简介.md`。
- 章节型文件保持现有编号体系；不要为了补齐缺失编号而改名。
- 历史文件如果从空格命名迁移为下划线命名，必须同步更新 `_sidebar.md` 和所有 Markdown 互链。

### 图片引用
- 图片统一存放在项目根目录 `/img/技术/`，按主题分子目录。
- 图片目录和文件名使用小写短横线命名，避免 `image.png`、空格、下划线或大小写混杂。
- Markdown 中必须使用从站点根开始的绝对路径，例如 `/img/技术/多线程/thread-states.png`。
- 禁止使用相对图片路径，例如 `../../img/` 或 `../../../img/`。

### Agent 导航
- 本项目统一使用大写 `AGENTS.md` 作为 agent 导航文件名。
- 移动、增加、删除关键目录后，同步更新当前目录及上级目录的 `AGENTS.md`。
