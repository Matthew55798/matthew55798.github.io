# 常用框架

本章节整理 Java 后端开发中最常见的框架体系。目录按章节组织：

1. [Spring](/软件工程/技术/常用框架/第1章%20Spring.md)
2. [Spring Boot](/软件工程/技术/常用框架/第2章%20Spring%20Boot.md)
3. [MyBatis](/软件工程/技术/常用框架/第3章%20MyBatis.md)
4. [MyBatis Plus](/软件工程/技术/常用框架/第4章%20MyBatis%20Plus.md)

Spring 章节聚焦 Spring Framework、Spring MVC、IoC、AOP 和事务；Spring Boot 章节聚焦自动配置、Starter、配置绑定、参数校验、Actuator 等工程化能力；MyBatis 章节聚焦 Mapper 代理、动态 SQL、结果映射、插件和缓存；MyBatis Plus 章节预留用于整理官网指南和插件内容。
