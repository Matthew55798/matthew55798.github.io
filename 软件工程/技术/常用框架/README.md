# 常用框架

本章节整理 Java 后端开发中最常见的框架体系。目录按主题组织：

1. [Spring](/软件工程/技术/常用框架/Spring.md)
2. [Spring Boot](/软件工程/技术/常用框架/Spring_Boot.md)
3. [MyBatis](/软件工程/技术/常用框架/MyBatis.md)
4. [Netty 与 WebFlux](/软件工程/技术/常用框架/Netty与WebFlux.md)
5. [数据库连接池](/软件工程/技术/常用框架/数据库连接池.md)

Spring 章节聚焦 Spring Framework、Spring MVC、IoC、AOP 和事务；Spring Boot 章节聚焦自动配置、Starter、配置绑定、参数校验、Actuator 等工程化能力；MyBatis 章节聚焦 Mapper 代理、动态 SQL、结果映射、插件和缓存；Netty 与 WebFlux 聚焦事件循环、Reactor 模型与 IO 选型；数据库连接池聚焦 HikariCP 与 Druid 的原理、参数调优与对比。
