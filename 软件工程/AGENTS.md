## CONVENTIONS

- 新增技术文档优先放入最贴近主题的子目录，不要散落在 `技术/` 根目录。
- AI、LLM业务实战与 Vibe Coding 统一放在 `技术/AI/` 下。
- Markdown 文档文件名尽量不要使用空格，使用下划线 `_` 分隔语义段，便于 sidebar 和文档互链维护。
- 章节型文件使用 `第X章_标题.md` 格式；历史文件迁移时必须同步更新 `_sidebar.md` 和所有 Markdown 互链。
- 图片必须放在项目根目录 `/img/技术/` 下按主题分目录管理，Markdown 中使用从站点根开始的绝对路径。
- 图片目录和文件名使用小写短横线命名，避免 `image.png`、空格、下划线和大小写混杂。
- 代码块需标注语言，例如 `java`、`sql`、`bash`、`python`。
- 本项目统一使用大写 `AGENTS.md` 作为 agent 导航文件名。

## NOTES

- `技术/参考资料/` 是资料归档目录，不展示在 sidebar；正文可以按需直链引用。
- `常用命令/Linux常用命令/` 目录下包含 `Windows常用命令.md`，属于历史路径。
- LLM 实战章节文件体积较大，检索或批量修改时注意范围控制。
