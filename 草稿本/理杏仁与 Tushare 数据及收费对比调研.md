# 理杏仁 Open API 与 Tushare 官方文档调研

**调研日期：** 2026-06-28  
**调研对象：**

- 理杏仁 Open API：`https://www.lixinger.com/open/api/doc?api-key=cn/company/fundamental/non_financial`
- Tushare Pro：`https://tushare.pro/`

## 结论摘要

如果目标是做 A 股公司估值、财务、基本面类研究，理杏仁和 Tushare 都能覆盖，但产品定位明显不同：

- **理杏仁 Open API** 更像“已整理好的投研指标 API”。它按市场和数据组收费，接口颗粒较粗，适合直接拿公司、指数、行业、基金、宏观等结构化指标做研究或看板。目标接口 `cn/company/fundamental/non_financial` 聚焦 A 股非金融公司基本面/估值指标，例如 PE、PB、PS、PEV、股息率、市值及历史分位等。
- **Tushare Pro** 更像“量化数据平台”。它覆盖面更宽，资产类别更多，接口拆分更细，A 股、基金、期货、期权、债券、外汇、指数、港股、宏观、新闻公告、研报、分钟和实时数据等都有涉及。常规接口按积分门槛控制，分钟、港美股、新闻公告等按独立权限收费。
- **收费上**，理杏仁 A 股公司数据组官方原价为 **788 元/年或 90 元/月**；Tushare 常规积分权限从免费 120 积分到 2000/5000/10000/15000 积分分层，对应官方价格为 **0/200/500/1000/1500 元/年**。但 Tushare 的分钟、实时、港美股、新闻公告等需要额外单独开通。
- **选型建议**：重投研指标完整性和使用便利性，优先理杏仁；重资产类别覆盖、量化研究、Python 生态、分钟/实时/公告新闻等数据，优先 Tushare。

## 目标接口：理杏仁 A 股非金融公司基本面数据

用户指定的理杏仁文档页对应 API：

```text
POST https://open.lixinger.com/api/cn/company/fundamental/non_financial
```

官方前端模型显示：

- 标题：Fundamental data API
- 描述：获取 PE、PB 等基本面数据
- 请求方式：POST
- 典型请求参数：
  - `token`
  - `date` 或 `startDate` / `endDate`
  - `stockCodes`
  - `metricsList`
- 示例股票代码：`300750`、`600519`、`600157`
- 指标方向：市盈率 TTM、市净率、市销率 TTM、PEV、股息率、市值，以及部分估值指标的历史分位/统计位置等

需要注意：理杏仁的 `fundamental` 接口主要是估值和基本面衍生指标，不等同于完整三大财务报表。完整财报类数据在另一类 `fs` 接口中，例如：

```text
POST https://open.lixinger.com/api/cn/company/fs/non_financial
```

## Tushare 对应数据能力

针对理杏仁目标接口中的 A 股公司估值/基本面数据，Tushare 大致需要组合以下接口：

| 需求 | Tushare 典型接口 | 官方权限信息 |
|---|---|---|
| A 股日行情 | `daily` | 120 积分起，非复权日线数据可免费层使用 |
| 周/月行情 | `weekly`、`monthly` | 2000 积分 |
| 复权行情 | `pro_bar` | 2000 积分，分钟、指数、基金、期货除外 |
| 每日估值/交易指标 | `daily_basic` | 2000 积分起 |
| 利润表 | `income` | 权限表中属于财务数据类 |
| 资产负债表 | `balancesheet` | 权限表中属于财务数据类 |
| 现金流量表 | `cashflow` | 权限表中属于财务数据类 |
| 财务指标 | `fina_indicator` | 权限表中列为财务指标数据 |

因此，如果只做 A 股日频估值研究，Tushare 需要至少关注 `daily_basic`、行情和财务指标类接口的积分要求；如果还要分钟、实时、公告、新闻、港美股，则需要额外购买独立权限。

## 选型建议

### 优先选择理杏仁的情况

- 主要研究对象是 A 股、港股、指数、行业、基金、宏观中的投研指标。
- 希望少组合接口，直接获得估值、财务和基本面衍生指标。
- 更重视指标口径的一致性、历史分位、估值统计等“投研成品数据”。
- 用量不高，按数据组订阅的成本和维护复杂度可接受。

### 优先选择 Tushare 的情况

- 需要更广资产类别：股票、基金、期货、期权、债券、外汇、指数、港股、宏观等。
- 需要分钟、实时、新闻、公告、研报、政策法规等扩展数据。
- 已经使用 Python/量化研究工作流，希望接入成熟 SDK 和社区生态。
- 需要更低成本拿到 A 股常规日频数据，并能接受按接口组合数据和处理字段口径。

### A 股公司基本面专项建议

如果只围绕“理杏仁目标接口”做 A 股非金融公司的 PE/PB/PS/股息率/市值/历史估值位置等指标：

- 理杏仁：开通 CN company 数据组即可覆盖该类 Open API，价格为 788 元/年，接口集中，使用路径清晰。
- Tushare：可用 `daily_basic`、`fina_indicator` 和财务报表接口组合实现，2000 积分层起步价格更低，但需要自行处理不同 API 的字段、日期、复权、财报期、TTM 和指标口径。

因此，若目标是快速搭建投研看板或知识库案例，理杏仁效率更高；若目标是量化回测或多因子数据底座，Tushare 更适合作为主数据源。

## 风险与待确认项

- 两个平台价格和权限都可能调整，正式购买前应再次查看官方价格页或权限中心。
- 理杏仁本次提取到的是官方价格接口公开返回的原价；如果账号内存在优惠券、活动价、种子价，实际支付价格可能不同。
- Tushare 各接口字段、最低积分和更新频率应以具体接口文档为准；本调研主要基于官方权限总表和收费说明。
- 两边财务指标口径可能不同，例如 TTM、扣非、分红、复权、市值计算、财报发布时间处理等；严肃投资研究或回测前需要抽样对账。
- Tushare 独立权限中的机构价格为个人价格 10 倍；理杏仁是否有企业授权、商用限制和发票政策，需购买前查看账号内订单协议或联系官方确认。
