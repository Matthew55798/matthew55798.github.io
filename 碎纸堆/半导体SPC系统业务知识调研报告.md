## 一、半导体制造工艺流程

### 1.1 制造流程概览

半导体制造是将空白硅晶圆转化为包含数十亿晶体管的集成电路的复杂过程。现代芯片制造涉及 **300-1000+个工艺步骤**，需要 **80-120次循环迭代的"层构建循环"**。

制造流程分为四大阶段：

| 阶段 | 内容 | 迭代次数 | 主要设备厂商 |
|------|------|----------|--------------|
| **前段制造（Front-End Fab）** | 晶圆上构建晶体管和互连层 | 80-120次/晶圆 | ASML、AMAT、Lam、TEL、KLA |
| **晶圆测试（Wafer Test）** | 探针台测试每个芯片电性能 | 1次/晶圆 | Teradyne、Advantest |
| **后段组装（Assembly）** | 晶圆切割、封装、键合 | 1次/芯片 | AMAT、K&S |
| **模块集成（Module Integration）** | Chiplet集成、封装测试 | 1次/模块 | 多厂商 |

### 1.2 核心六步循环（Layer-Build Loop）

每个芯片层都通过相同的六步循环构建：

```
┌─────────────────────────────────────────────────────────┐
│                    层构建循环 (80-120次)                  │
├─────────────────────────────────────────────────────────┤
│  1. Clean      → 表面清洁准备                            │
│  2. Deposit    → 沉积薄膜（CVD/PVD/ALD）                 │
│  3. Litho      → 光刻 patterning                         │
│  4. Etch       → 刻蚀去除材料                            │
│  5. Clean      → 清除光刻胶                              │
│  6. Metrology  → 检测/量测                               │
└─────────────────────────────────────────────────────────┘
```

### 1.3 关键工艺详解

#### （1）氧化（Oxidation）
- **目的：** 在硅表面生长二氧化硅（SiO₂）绝缘层
- **温度：** 800-1300°C
- **类型：** 
  - 干氧化（Dry Oxidation）：O₂气氛，生长致密氧化层
  - 湿氧化（Wet Oxidation）：O₂+H₂O，生长速率更快
- **应用：** 栅极氧化层、隔离层、掩膜层

#### （2）光刻（Photolithography）
- **核心作用：** 将电路图形从掩膜版转移到晶圆表面
- **步骤：**
  1. 涂胶（Photoresist Coat）：旋涂光敏材料
  2. 曝光（Exposure）：UV/EUV光通过掩膜投影
  3. 显影（Develop）：去除曝光/未曝光区域
- **技术演进：**
  - DUV（深紫外，193nm）：成熟节点
  - EUV（极紫外，13.5nm）：5nm/3nm/2nm先进节点（ASML独家）
  - SADP/SAQP（多重曝光）：扩展DUV能力

#### （3）刻蚀（Etching）
- **目的：** 选择性去除未保护的晶圆材料
- **类型：**
  - **湿刻蚀（Wet Etching）：** 化学溶液腐蚀
    - 优点：高选择性、不损伤材料
    - 缺点：等向性、不适合亚微米特征
  - **干刻蚀（Dry Etching/Plasma Etch）：** 真空等离子体
    - 优点：高等向性、精密控制
    - 缺点：选择性较低、可能损伤材料
- **关键参数：** 刻蚀深度、侧壁角度、均匀性

#### （4）薄膜沉积（Deposition）
| 技术 | 原理 | 应用 |
|------|------|------|
| **CVD**（化学气相沉积） | 气相化学反应在表面沉积 | 氧化物、氮化物、多晶硅 |
| **PVD**（物理气相沉积） | 离子溅射靶材沉积 | 金属层（Al、Ti、Ta） |
| **ALD**（原子层沉积） | 原子层级逐层沉积 | 超薄高介电常数层 |
| **ECD**（电化学沉积） | 电镀沉积 | 铜互连 |

#### （5）离子注入（Ion Implantation）
- **目的：** 改变硅的电学性质，形成N型/P型区域
- **掺杂剂：** 硼（B）、磷（P）、砷（As）
- **参数：** 注入剂量、注入能量、注入深度
- **应用：** 源/漏极形成、阈值电压调节

#### （6）化学机械抛光（CMP）
- **目的：** 平坦化晶圆表面，为下一层光刻做准备
- **原理：** 化学浆料+机械研磨
- **重要性：** 多层互连必不可少的步骤
- **监控参数：** 去除量、平坦度、均匀性

#### （7）金属化（Metallization）
- **目的：** 创建互连层，连接各晶体管
- **材料演进：** Al → Cu（铜互连，IBM 1997首创）
- **技术：** Damascene工艺（双大马士革）
- **层数：** 先进芯片可达10+金属层

## 二、SPC在半导体行业的应用

### 2.1 SPC的核心价值

在半导体制造中，SPC（统计过程控制）**不是简单的质量工具，而是生存必需品**：

- **纳米级精度：** 规格以纳米和ppb（十亿分之一）计量
- **极高成本：** 一次偏差可能导致整批晶圆报废，损失数百万美元
- **复杂变异：** 需区分正常波动与异常漂移
- **实时响应：** 0.1%良率提升价值百万美元

### 2.2 关键监控参数

#### 光刻工艺（Lithography）
| 参数 | 说明 | 监控重点 |
|------|------|----------|
| **CD（Critical Dimension）** | 关键尺寸/线宽 | 平均值、均匀性、边缘到中心差异 |
| **Overlay** | 层间对准精度 | X/Y方向偏移、旋转误差 |
| **Dose** | 曝光剂量 | 能量均匀性 |
| **Focus** | 聚焦深度 | 焦平面稳定性 |

**SPC策略：** 使用EWMA/CUSUM检测微小漂移（0.5-1.5σ），Western Electric Rules检测非随机模式。

#### 刻蚀工艺（Etching）
| 参数 | 说明 |
|------|------|
| **刻蚀深度** | 目标深度精度 |
| **线宽变化** | 刻蚀后CD偏差 |
| **均匀性** | 晶圆内（Within-Wafer）、晶圆间（Wafer-to-Wafer） |
| **侧壁角度** | 刻蚀剖面控制 |

**SPC收益：** 及时识别腔体条件变化、耗材老化、污染风险。

#### 薄膜沉积（CVD/PVD/ALD）
| 参数 | 说明 |
|------|------|
| **膜厚** | 目标厚度±Å级 |
| **折射率** | 薄膜光学性质 |
| **电阻率** | 导电性 |
| **均匀性** | 49点晶圆图测量 |
| **沉积速率** | 实时监控（in-situ传感器） |
| **腔体间匹配** | 多腔体工具一致性 |

#### 离子注入
| 参数 | 说明 |
|------|------|
| **注入剂量** | 掺杂浓度 |
| **注入能量** | 掺杂深度 |
| **均匀性** | 扫描一致性 |

#### CMP工艺
| 参数 | 说明 |
|------|------|
| **去除量** | 材料去除厚度 |
| **平坦度** | 表面平整度 |
| **均匀性** | 晶圆各区域一致性 |

### 2.3 设备能力监控

#### Tool Match（设备匹配）
- **目的：** 确保同类设备产出一致
- **方法：** 比较图表（Comparison Charts）
- **参数：** CD、膜厚、刻蚀深度等关键指标
- **重要性：** 避免因设备差异导致的良率波动

#### Chamber Match（腔体匹配）
- **场景：** 多腔体集群工具（Cluster Tool）
- **监控：** 各腔体独立SPC控制图
- **目标：** Cpk ≥ 1.33（标准），Cpk ≥ 1.67（关键参数），Cpk > 1.8（世界级）

### 2.4 出货稳定性分析

- **批次间一致性：** 监控Lot-to-Lot变异
- **长期趋势分析：** EWMA检测渐变漂移
- **良率关联：** SPC数据与电测结果交叉分析
- **出货决策：** SPC状态作为放行依据

## 三、半导体行业关键术语

### 3.1 系统架构术语

#### MES（Manufacturing Execution System）- 制造执行系统
**定位：** 晶圆厂的"大脑"——决策中心

**核心功能：**
- 决定"哪个晶圆去哪台设备、用什么配方"
- 管理配方（Recipe）版本控制、金版管理
- 记录完整生产历史
- 工作流程（Workflow/Traveler）管理
- 物料追踪（Lot/Wafer/Die Tracking）

**关键模块：**
| 模块 | 功能 |
|------|------|
| **EDC（Engineering Data Collection）** | 工程数据采集计划、参数定义 |
| **RCP（Recipe Management）** | 配方管理、版本控制 |
| **WIP Tracking** | 在制品追踪 |
| **Material Genealogy** | 物料谱系追溯 |

#### EAP（Equipment Automation Program）- 设备自动化程序
**定位：** MES与设备之间的"翻译器"

**核心职责：**
| 功能 | 说明 |
|------|------|
| **SECS/GEM通信** | 将MES指令转化为SECS/GEM协议消息 |
| **配方下载验证** | 下载配方并比对金版参数 |
| **数据采集存储** | 收集设备运行数据（温度、压力、功率） |
| **状态监控上报** | 设备状态变化实时通知MES |

**工作流程示例：**
```
MES指令："将Lot B在PVD-07执行Step 5"
    ↓
EAP验证：
  - PVD-07状态正常
  - 配方已下载
  - Lot B前序步骤完成
  - 配方参数与金版一致
    ↓
EAP执行：
  - 通过SECS/GEM发送启动命令
  - 实时采集过程数据
  - 完成后上报MES
```

#### EDC（Engineering Data Collection）- 工程数据采集
**定位：** MES的数据采集模块

**功能：**
- 定义采集计划（采集什么、何时采集、采集频率）
- 定义参数、参数集、采集点、样本、采样点
- 支持 Job/Lot/Wafer 层级采集
- Wafer采样规则设置（TOP+N、BOTTOM+N）
- 数据来源：设备接口自动采集或文件解析（txt/excel/csv）

#### FDC（Fault Detection and Classification）- 故障检测与分类
**定位：** 设备传感器数据的实时监控

**数据类型：** Equipment Trace（ET）数据
- 压力、温度、气流、RF功率、运动、时间等时序数据
- 结合工艺上下文（设备、腔体、配方、步骤）

**功能：**
| 功能 | 说明 |
|------|------|
| **实时监控** | 监控设备行为 |
| **异常检测** | 指标超限触发警报 |
| **工具保护** | 防止设备在异常状态运行 |
| **良率关联** | FDC指标与下游电测/缺陷数据关联 |
| **根因分析** | 识别变异来源（设备/腔体/步骤） |

#### APC（Advanced Process Control）- 先进工艺控制
**定位：** 主动工艺调整系统

**组成：**
- **FDC：** 处理前两个需求（更广参数域、更短检测时间）
- **MBPC（Model-Based Process Control）：** 处理后两个需求（频繁测量、减少晶圆状态变异）

**能力：**
- 多变量传感器监控
- 模型预测（VM - Virtual Metrology）
- Run-to-Run（R2R）控制
- 反馈/前馈调整

### 3.2 物料与生产术语

| 术语 | 定义 |
|------|------|
| **Lot（批次）** | 生产单位，通常25片晶圆一起处理 |

| **FOUP** | 前开式统一晶圆盒（300mm自动化传输载体） |

| **Die（芯片）** | 晶圆上的单个电路单元 |
| **Substrate** | 基板/衬底（即Wafer） |
| **Carrier** | 载体（FOUP/SMIF） |

### 3.3 设备与工艺术语

| 术语 | 定义 |
|------|------|
| **Recipe（配方）** | 设备运行参数集（温度、压力、气体流量、时间） |
| **Process Program** | 配方的SECS/GEM术语 |
| **Chamber（腔体）** | 设备内的工艺处理单元 |
| **Cluster Tool** | 多腔体集群设备（含多个工艺腔、负载锁、传输机器人） |
| **Load Lock** | 真空过渡腔体 |
| **Stepper/Scanner** | 步进式/扫描式光刻机 |
| **Track** | 涂胶显影轨道（涂胶→曝光→显影） |
| **Module** | 设备子单元（腔体、负载锁等） |
| **Tool** | 工艺设备 |

### 3.4 质量控制术语

| 术语 | 定义 |
|------|------|
| **OCAP（Out-of-Control Action Plan）** | 异常响应计划 |
| **OOS（Out of Specification）** | 超出规格限 |
| **OOC（Out of Control）** | 超出控制限 |
| **OOW（Out of Warning）** | 超出警告限 |
| **Cpk** | 过程能力指数（≥1.33标准，≥1.67关键） |

| **IPQC（In-Process Quality Control）** | 过程质量控制 |
| **OQC（Outgoing Quality Control）** | 出货质量控制 |

## 四、OCAP（Out-of-Control Action Plan）

### 4.1 定义与作用

**OCAP（异常响应计划）** 是SPC系统检测到异常后执行的标准化响应流程，确保变异被系统化处理，防止问题蔓延。

**传统OCAP的问题：**
- 流程复杂冗余
- 过度依赖人工判断
- 响应慢、成本高
- 缺乏透明度和追溯性

### 4.2 OCAP流程示例（CD异常）

```
SPC检测到刻蚀设备CD异常
    ↓
┌─────────────────────────────────────────────┐
│  OCAP触发                                    │
├─────────────────────────────────────────────┤
│  Step 1: 自动Hold异常Lot                     │
│          → 暂停所有相关批次                  │
│  Step 2: 运行测试晶圆                        │
│          → 使用标准配方验证设备              │
│  Step 3: 结果判断                            │
│          → 合格：审查并释放Hold Lot          │
│          → 不合格：设备下线，执行PM          │
│  Step 4: Lot处置                             │
│          → 根据实测vs规格判定                │
│  Step 5: 文档记录                            │
│          → 根因、纠正措施、预防措施          │
└─────────────────────────────────────────────┘
```

### 4.3 新型OCAP改进

| 改进点 | 效果 |
|------|------|
| **预防性维护** | 减少突发故障 |
| **实时监控技术** | 提前预警 |
| **自动化决策流程** | 减少人工依赖 |
| **数字化追溯** | 全程记录可审计 |

**实施效果（案例数据）：**
- 机台停机时间减少24小时/周
- 晶圆产量增加23片/周
- 探测良率提升1.1%
- 异常响应速度提升50-90%

## 五、数据采集方式

### 5.1 数据源分类

| 数据源 | 说明 | 采集方式 |
|------|------|----------|
| **设备传感器** | 温度、压力、功率、气流等实时数据 | SECS/GEM Trace |
| **在线量测（Inline Metrology）** | 工艺过程中即时测量 | 设备接口自动采集 |
| **离线量测（Offline Metrology）** | 专用量测设备测量 | 文件解析/API接口 |
| **IQC（Incoming QC）** | 来料检验数据 | 手动录入/自动接口 |
| **电测数据（E-Test）** | 晶圆探针测试数据 | ATE设备接口 |

### 5.2 在线量测（Inline Metrology）

**设备类型：**
| 设备 | 测量参数 |
|------|----------|
| **CD-SEM** | 关键尺寸（线宽） |
| **Ellipsometer** | 薄膜厚度、折射率 |
| **Overlay Tool** | 层间对准精度 |
| **OCD（Scatterometry）** | 光学CD测量 |
| **Defect Inspection** | 缺陷检测（明场/暗场） |
| **XRD** | 晶格结构、间距 |

**特点：**
- 高频采集（每个Lot/每片Wafer）
- 实时反馈控制
- 与生产流线集成

### 5.3 离线量测（Offline Metrology）

**场景：**
- 验证性测量
- 深度分析（如截面SEM）
- 特殊参数测量

**数据流：**
```
量测设备 → 生成文件 → SPC系统解析 → 自动录入数据库
```

### 5.4 IQC（Incoming Quality Control）

**检查内容：**
| 项目 | 说明 |

## 六、通信协议与接口标准

### 6.1 SEMI标准体系

**SEMI（Semiconductor Equipment and Materials International）** 定义了半导体设备通信的国际标准。

| 标准代号 | 名称 | 作用 |
|----------|------|------|
| **SEMI E4** | SECS-I | 串行通信（RS-232，已较少使用） |
| **SEMI E37** | HSMS | 高速SECS消息服务（TCP/IP） |
| **SEMI E5** | SECS-II | 消息内容/结构定义 |
| **SEMI E30** | GEM | 设备通用模型（行为规范） |
| **SEMI E87** | Carrier Management | FOUP载体管理 |
| **SEMI E90** | Substrate Tracking | 晶圆追踪 |
| **SEMI E40** | Process Job Management | 工艺作业管理 |
| **SEMI E94** | Control Job Management | 控制作业管理 |
| **SEMI E157** | Module Process Tracking | 模块工艺追踪 |
| **SEMI E120/E125/E132** | Interface A/EDA | 高频数据采集接口 |

### 6.2 SECS/GEM协议详解

#### 协议栈结构
```
┌────────────────────────────────────────┐
│  GEM（E30）- 行为层                     │
│  定义设备如何响应命令                    │
├────────────────────────────────────────┤
│  SECS-II（E5）- 消息层                  │
│  定义消息结构（Stream/Function）        │
├────────────────────────────────────────┤
│  HSMS（E37）- 传输层                    │
│  TCP/IP以太网通信                       │
│  （或 SECS-I 串行通信）                 │
└────────────────────────────────────────┘
```

#### 消息结构
```
Stream: 消息类别（1-9）
Function: 类别内具体动作（如F1、F2...）

示例：
S1F1 - "Are You There?"（你在线吗？）
S1F2 - "Online Data"（是的，我在线）
S6F11 - Event Report（事件报告）
S7F3 - Process Program Upload（配方上传）
```

#### 状态模型（State Model）

**控制状态（Control State）：**
| 状态 | 说明 |
|------|------|
| **Offline** | 未与Host通信 |
| **Online-Local** | Host可监控但不可控制 |
| **Online-Remote** | Host完全控制（自动化目标） |

**处理状态（Processing State）：**
| 状态 | 说明 |
|------|------|
| **Idle** | 空闲待机 |
| **Processing** | 正在处理晶圆 |
| **Setup** | 设置/维护模式 |

#### GEM核心能力

| 能力 | 说明 |
|------|------|
| **数据采集** | Status Variables（SV）、Data Variables（DV） |
| **事件报告** | Collection Events（CE）+ 自定义报告 |
| **告警管理** | 告警设置/清除通知 |
| **远程命令** | Remote Commands（RCMD） |
| **配方管理** | Process Program Management（PPM） |

### 6.3 GEM300扩展（300mm自动化）

**GEM300** 是为300mm全自动晶圆厂扩展的标准集合：

| 标准 | 功能 |
|------|------|
| **E87** | FOUP载体到达/离开/状态管理 |
| **E90** | 单片晶圆在集群设备各腔体间移动追踪 |
| **E40** | 工艺作业（Process Job）详细执行 |
| **E94** | 控制作业（Control Job）高层调度 |
| **E157** | 腔体级工艺步骤追踪 |

### 6.4 Interface A / EDA（Equipment Data Acquisition）

**定位：** 专为高频数据采集设计的并行接口

**特点：**
- 与SECS/GEM并行运行
- 高带宽传感器数据管道
- 支持AI分析/预测性维护
- 不替代GEM，而是补充

```
┌─────────────┐     SECS/GEM      ┌─────────────┐
│             │ ←────控制─────────→ │             │
│   设备      │                    │    MES      │
│             │                    │             │
│             │ ←──高频数据────────→ │  分析引擎   │
│             │     Interface A    │  (AI/FDC)   │
└─────────────┘                    └─────────────┘
```

## 七、SPC控制图与方法

### 7.1 控制图类型

| 控制图 | 应用场景 | 特点 |
|--------|----------|------|
| **X-bar & R Chart** | 监控平均值和极差 | 基础Shewhart图 |
| **I-MR Chart** | 单值移动极差图 | 适用于低采样频率 |
| **EWMA** | 指数加权移动平均 | 对小漂移敏感（0.5-1.5σ） |
| **CUSUM** | 累积和图 | 检测持续性偏移 |

### 7.2 Western Electric Rules（Nelson Rules）

半导体SPC常用8条规则检测非随机模式：

| 规则 | 模式 | 说明 |
|------|------|------|
| Rule 1 | 单点超限 | 1点超出3σ控制限 |
| Rule 2 | 9点同侧 | 连续9点在中心线同一侧 |
| Rule 3 | 6点递增/递减 | 连续6点呈趋势 |
| Rule 4 | 14点交替 | 连续14点上下交替 |
| Rule 5 | 2/3点超2σ | 连续3点中2点超出2σ |
| Rule 6 | 4/5点超1σ | 连续5点中4点超出1σ |
| Rule 7 | 15点在1σ内 | 连续15点在中心线±1σ内 |
| Rule 8 | 8点超1σ | 连续8点在中心线外超过1σ |

**注意：** 不建议盲目使用所有规则，应根据工艺特性选择，并配套可行的OCAP。

### 7.3 变异源分析

半导体制造存在多层变异：

```
变异模型：
Xijk = μ + bi + wj(i) + pjk(i)

μ: 总体均值
bi: 批次效应（Lot-to-Lot）
wj(i): 晶圆效应（Wafer-to-Wafer）
pjk(i): 位点效应（Site-to-Site / Within-Wafer）
```

**SPC应分别监控各变异源：**
- 批次间变异（Batch/Lot层面）
- 晶圆间变异（Wafer层面）
- 晶圆内变异（Site/点位层面）
- 腔体间变异（Chamber层面）
- 设备间变异（Tool层面）

### 7.4 过程能力指标

| 指标 | 公式 | 目标值 |
|------|------|--------|
| **Cp** | (USL-LSL)/(6σ) | ≥1.33 |
| **Cpk** | min[(USL-μ)/(3σ), (μ-LSL)/(3σ)] | ≥1.33（标准）<br>≥1.67（关键参数）<br>≥1.8（世界级） |

## 八、行业最佳实践

### 8.1 SPC实施流程

```
Step 1: 确定关键参数
        → CD、膜厚、Overlay、植入剂量、刻蚀深度、颗粒数
        
Step 2: 建立数据采集
        → 设备传感器、在线量测、离线量测
        
Step 3: 配置规则和OCAP
        → 选择控制图类型、启用Western Electric规则
        → 定义每种违规类型的OCAP
        → 设置通知升级路径
        
Step 4: 培训组织
        → 操作员、工程师、管理层
        
Step 5: 持续维护
        → 季度审查控制限
        → 分析误报率
        → 更新OCAP
        → 添加新参数
```

### 8.2 系统集成最佳实践

| 建议 | 说明 |
|------|------|
| **MES深度集成** | 自动Lot Hold、异常联动 |
| **FDC数据融合** | 设备数据+量测数据联合分析 |
| **配方联动** | SPC异常触发配方调整（R2R） |
| **追溯闭环** | SPC记录关联物料谱系 |
| **数字化OCAP** | 自动化工作流、减少人工依赖 |

### 8.3 数据质量要求

| 维度 | 要求 |
|------|------|
| **完整性** | 关键参数全覆盖（IQC/IPQC/OQC） |
| **准确性** | 测量系统分析（MSA）验证 |
| **时效性** | 实时采集、实时监控 |
| **一致性** | 跨工具/腔体可比 |
| **可追溯** | Lot/Wafer/Chamber/Recipe绑定 |

### 8.4 常见问题与对策

| 问题 | 对策 |
|------|------|
| **误报过多** | 精简规则、调整权重、动态限值 |
| **漏报关键变异** | 增加EWMA/CUSUM、细分变异源 |
| **响应慢** | 数字化OCAP、自动化工作流 |
| **跨设备差异大** | Tool Match监控、标准化作业 |
| **数据孤岛** | MES/EAP/FDC/SPC统一平台 |
